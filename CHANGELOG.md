# Luxor changelog

## v9 — open-source release package

Repository
- Laid out for publishing as a GitHub repo: visual `README.md` (CAD renders with the real UI on the glass, screen strip, build-in-five-steps flow, status table), docs moved into `docs/`, older fix notes into `docs/history/`.
- **`docs/BOM.md` + `docs/bom.csv`** — every part with spec, quantity, rough price, order gate. Flags that Waveshare lists the cover-glass board as **ESP32-S3-Touch-LCD-1.46** and the 1.46B *without* glass.
- **`docs/WIRING.md` + `docs/images/wiring.svg`** — pin-by-pin map of every GPIO the firmware uses (from `board.c` / `audio.c`), I2C addresses, IO-expander lines, power path, and the battery-connection procedure. The SVG is generated by `docs/images/make_wiring_svg.py`.
- **`docs/REQUIREMENTS.md`** — 35 requirements (function, interface, performance, physical, safety, openness), each with a verification method and its real status.
- **`docs/PUBLISHING.md`** — copy-paste commands for a fresh Ubuntu terminal: install `gh`, sign in, create the repo, push, release binaries and STLs.
- `docs/RELEASE_NOTES_v9.md`, `.gitattributes` (STLs are binary for diffs), updated `.gitignore`.

Firmware
- **44 px touch areas everywhere** (the brief's ease-of-use rule, previously only checked on STEPS). `size_control()` in `ui.c` keeps each control's drawn size and adds an invisible extended click area (`lux_hit_pad()` in `layout.h`). Applies to HOME, calculator keys, maze buttons, motion buttons, steppers, switches, sliders and SAVE TIME.
- MOTION buttons re-spaced (axis row 40 px tall at y = 300, ZERO GYRO 32 px at y = 348) so their touch areas don't overlap; stepper buttons 10 px apart (was 6).
- Version v9.

Checks
- `test_layout.c`: new section — every control group has ≥ 44 px touch areas and no overlaps (HOME, calculator, maze, motion, music, display arrows, stepper and switch rows).
- `tools/ui_sim check`: new touch audit of every real clickable LVGL object on all 11 screens × 6 themes. It found the 38 px SAVE TIME button, fixed.
- `hardware/render_all.sh` re-renders every STL; `hardware/check_stl_fresh.py` fails if committed STLs no longer match the sources.
- `check_print.py` and `check_fit.py` now run from any folder; `check_print.py` fails instead of passing when it finds no STLs.
- CI (`.github/workflows/build.yml`): host tests + UI audit, CAD job (STL freshness, printability, fit), firmware build.

Images
- `hardware/hero.scad` + `hardware/renders/make_hero.py` — README hero: assembled watch on a strap rendered from the CAD, with the simulator's real UI frame on the glass.
- `hardware/renders/make_exploded.py` — noir exploded view for GitHub's light theme, ivory for dark (`<picture>`).
- `tools/ui_sim/readme_images.py` — screen strip and galleries for the README (replaces the stale v8 screenshot that still showed "Luxor v7"); `make gallery` now orders screens by app number.
- `prebuilt/flash_prebuilt_v9.sh` — flash from Linux/WSL/macOS without ESP-IDF, after a hash check.

## v8 — luxury pass and the printable watch

Interface (see `docs/v8_screens_*.png`)
- **Inter typeface** everywhere (Inter Medium for text, Inter Display for the big sizes; SIL OFL), generated into `main/fonts/` with the LVGL symbols merged in. Montserrat 16–48 removed from the build.
- **Motion.** Every screen change dissolves in over 200 ms. At boot, the LUXOR wordmark shows on black and the watch fades in underneath. Neither blocks touch.
- **Press feedback.** Pill-shaped buttons settle inwards a pixel on press and ease back over 90 ms. Hexagon tiles tint gold and sink to 95 %, using the image widget's own zoom. LVGL's layer zoom made the pressed tile vanish in the simulator, so it isn't used.
- **STEPS: three activity rings** — steps (gold), active minutes against 30 (rose gold), distance against the goal distance (platinum). Numbers sit in a row under the rings, with thousands grouped (6,240). The title now matches the tile ("STEPS", was "FITNESS").
- **MUSIC:** a five-bar level meter in the disc breathes while a track plays and rests when paused. The screen redraws at 20 Hz only while playing.
- **CALC:** real × ÷ − ± glyphs. The display uses 48 px light numerals and steps down to 28 px when the number would not fit.
- One-word titles everywhere: SET TIME → TIME, MOTION SETUP → MOTION.
- Fixed text that was clipped on screen: the STEPS goal and distance lines, the MUSIC footer, "ZERO GYRO", the MOTION readout, three Settings captions, the About power line, and "100%" in the battery badge (badge widened to 68 px).

Tools
- **`tools/ui_sim/`** — UI simulator that compiles the real `ui.c` against LVGL on a PC. `make check` audits every label on all 11 screens × 6 themes for clipped text and missing glyphs: it found 10 clipped strings and the missing ± glyph, all fixed. `make gallery` renders every screen.
- `main/fonts/generate_fonts.sh` regenerates the fonts reproducibly.

Tests
- `test_layout.c`: activity rings (inside the safe circle, rings not touching, open centre, clear of the title and stats), stat columns finger-sized and not overlapping, music level bars inside the disc. Superseded fitness geometry removed.

Case — full printable set (`hardware/`, see `hardware/README.md`)
- **Part 1, shell:** glass lip with a 0.3 mm gasket, black inner bezel, pocket for a flush gold inlay, integral 22 mm lugs with blind spring-bar holes, two **seamless flexure buttons** (no holes), USB-C mouth, mic hole, rotation-key notch.
- **Part 2, back cover:** three standoff bosses with counterbored M2×6 holes, a battery cradle for a 402530 cell, speaker slots, and an engraved back (LUXOR · HANDBUILT · No. 001, mirrored so it reads correctly from behind).
- **Part 3, bezel inlay:** silk gold, flush, with engraved hour indices (12 doubled).
- **Part 4, charging dock:** upright nightstand. The watch stands on a pedestal that holds the USB-C plug pointing up, leaning on a backrest, with the whole face visible. Weight pockets underneath.
- **Coupons** cut from the real geometry: A front band (lip, bore, inlay fit), B standoff plate, C lug pair.
- `check_print.py`: every STL is one watertight body on the bed with no overhang past 45° (widest bridge 3 mm).
- `check_fit.py`: no clash between any pair of parts, the glass, the board envelope or the cell; the flexure nubs just touch the board edge. Negative tests confirmed it catches an oversize inlay and over-long nubs.
- `assembly.scad` (assembled / exploded / section, noir or ivory), plus renders in `hardware/renders/`.
- Watch thickness 18.4 mm with the 4.2 mm cell.
- `ASSEMBLY.md` step list; `BOM.md` updated with printed parts and specs.

Verification done for this package
- `make -C tests` — all six suites pass.
- `tools/ui_sim make check` — all labels fit, all glyphs present.
- Full `idf.py build`, ESP-IDF 5.5.5, esp32s3: clean, 0 warnings in `main/`, app 1.45 MB (64 % of the 4 MB partition free).
- `hardware/check_print.py` and `hardware/check_fit.py` — all OK.
- NOT yet run on the watch or printed — see `HARDWARE_CHECKS.md`.

## v7 — battery badge (roadmap step 3)

Firmware
- **Battery percentage, top right of home.** Percentage plus an outlined battery glyph whose fill tracks the charge; turns red at 15 % or less; shows `--` when the ADC is unavailable. Sits inside the 188 px safe circle (outer corner 179.6 px from centre), clear of the clock strip and every hexagon. Not a control — taps on it still count as empty background, so the 2-tap/3-tap gestures are unchanged.
- **New `main/battery.c/.h` (host-tested).** 20 s low-pass filter, ±1 % dead band (no flicker between neighbours), first reading shown immediately, "unknown" only after 3 failed reads in a row, impossible voltages rejected. The volts→percent curve is unchanged from v6.
- `board.c` now only measures volts (ADC1 channel 7 = GPIO8, ×3 divider — unchanged). `board_battery_percent()` removed.
- The main loop reads the ADC once per second (every 5 s in standby) and the UI uses the cached value; v6 did 16 ADC reads on every UI frame.
- The home footer shows only the date (the percentage moved to the badge).
- Settings → About gains a **Battery** row with the filtered voltage, for multimeter calibration.
- Boot log prints `battery: X.XXX V -> N %` right after board init.
- Low-battery warning now uses the filtered voltage, so a load dip cannot trigger it.
- Version v7 (boot log, About, Settings footer).

Visual fixes (found by rendering the real `ui.c` on the host — see below)
- **Gradient banding.** Every screen's background gradient drew as a hard horizontal line across the middle in 16-bit colour (Noir Gold went 0x0020 → 0x0840 in one step at y ≈ 210; Ivory Gold showed faint pink/green tint bands). Fixed by enabling `CONFIG_LV_DITHER_GRADIENT=y` and ordered dithering on all 7 gradients. Delete your old `sdkconfig` so the new default is picked up.
- **Tile labels touched the hexagon edges.** "SETTINGS" measured 87 px at Montserrat 16 + 1 px tracking in a 76 px space. ui.c now measures all seven names and picks the largest font/tracking where every one fits (currently Montserrat 14, no tracking; widest 69 px). Geometry in `layout.h` (`LUX_TILE_LABEL_*`), checked by `test_layout.c`.
- Unused-function warning on `f24()` silenced; `main/` now builds with zero warnings.

Verification done for this package
- `make -C tests` — all six suites pass.
- Full `idf.py build` with ESP-IDF 5.5.5 for esp32s3: clean, 0 warnings in `main/`, app 1.50 MB (62 % of the 4 MB partition free). This build caught a `-Werror=format-truncation` in the new badge code, fixed before packaging.
- Home, About and Clock rendered from the real `ui.c` + LVGL 8.3.11 on the host at 412×412 (Ivory Gold, Noir Gold, Champagne Noir; 82 %, 9 %, 100 %, unknown).
- NOT yet run on the watch — see `HARDWARE_CHECKS.md`.

- `tests/test_layout.c`: battery badge fits the safe circle, clears the clock strip and all 7 tiles, glyph fits the badge; tile label box keeps a margin inside the hexagon.
